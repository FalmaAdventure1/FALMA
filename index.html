# Falma Adventure Website online shop celana gunung dan outdoor. - TikTok: https://www.tiktok.com/@falmaadventure.official - Shopee: https://id.shp.ee/eRbRMEV4 - Instagram: https://www.instagram.com/falmaadventure_official/ ## Struktur file ``` index.html halaman utama style.css tampilan app.js pita berjalan dan tahun footer img/ logo, ikon, dan latar gunung ``` ## Cara pasang di GitHub Pages 1. Buat repository baru di GitHub (Public), misalnya `falma-adventure`. 2. Klik **Add file > Upload files**, lalu upload `index.html`, `style.css`, `app.js`, dan folder `img`. Klik **Commit changes**. 3. Buka **Settings > Pages**. 4. Di **Branch**, pilih `main` dan folder `/ (root)`, lalu klik **Save**. 5. Tunggu 1 sampai 2 menit. Alamat web muncul di halaman itu, bentuknya `https://username.github.io/falma-adventure/`. ## Cara ubah isi - Link toko: edit bagian `href` di `index.html`. - Warna dan ukuran: edit `style.css`. - Tulisan pita berjalan: edit teks di dalam `` di `index.html`.
